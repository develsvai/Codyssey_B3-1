조회 결과에서 VPC, 서브넷, 인터넷 게이트웨이, 라우팅 테이블, 보안 그룹, 네트워크 인터페이스, EBS, 키페어, Elastic IP의 본인 태그 목록은 모두 빈 배열이다. 활성·정지·종료 중인 실습 인스턴스도 없다. 종료된 EC2 기록은 콘솔에 한동안 표시될 수 있으므로 인스턴스의 최종 상태를 함께 확인했다.

이번 EC2에는 Elastic IP를 할당하지 않았다. 자동 할당 공인 IPv4는 인스턴스 종료로 반납되므로 이전 접속 IP를 실습 주소로 재사용하지 않는다. VPC에 AWS가 자동 생성했던 기본 보안 그룹·라우팅 테이블·네트워크 ACL도 VPC와 함께 제거된다.

## 유지한 항목과 비용 확인 범위

- IAM 사용자와 연결한 정책은 이후 실습을 위해 유지했다. IAM 관리 권한을 부여하거나 다른 사용자의 정책을 변경하지 않았다.
- Mac의 SSH 개인키는 권한 600으로 로컬 `.ssh` 폴더에 남아 있다. AWS 키페어는 삭제됐고 개인키 내용은 제출 저장소에 넣지 않았다.
- 공유 계정의 다른 자원과 기본 VPC는 정리 대상에서 제외했다.
- Billing 조회는 이번 IAM 권한에 포함되지 않아 실행하지 않았다. 자원 정리 완료는 이미 발생한 사용 요금이 없다는 뜻이 아니며, 공유 계정 전체의 비용을 증명하지도 않는다.
